# Design-and-Development-of-an-Autonomous-Water-Bodies-Cleaning-Vehicle

# Overview

The Autonomous Water Body Cleaning Vehicle is an intelligent robotic system designed to automatically remove floating waste from lakes, ponds, rivers, and other water bodies. The project aims to reduce water pollution while minimizing manual effort through autonomous navigation and waste collection.

# Objectives

* Automate the cleaning of water bodies.
* Reduce environmental pollution.
* Improve efficiency compared to manual cleaning.
* Promote sustainable environmental conservation.

# Features

* Autonomous navigation.
* Floating waste collection mechanism.
* Efficient garbage storage system.
* Low power consumption.
* Eco-friendly operation.
* Easy maintenance.

# Technologies and Components

* Microcontroller
* DC Motors
* Motor Driver
* Ultrasonic Sensors
* Battery
* Conveyor or Collection Mechanism
* Floating Chassis
* Power Management Circuit

# Working Principle

The vehicle moves autonomously across the water surface while detecting obstacles using sensors. Floating waste is collected through a mechanical conveyor or collection mechanism and stored inside a waste container. The system continues cleaning until the storage compartment is full or the cleaning cycle is completed.

# Applications

* Lakes
* Rivers
* Ponds
* Reservoirs
* Public Parks
* Industrial Water Bodies

# Future Scope

The project demonstrates an effective autonomous solution for cleaning floating waste, contributing to environmental protection and sustainable water resource management.
